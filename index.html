FHIR document viewer

A FHIR document Bundle - an International or European Patient Summary, a lab report, a prescription - shown the way a clinician reads it: what is critical first, what is missing or possibly outdated next, then the document, a dashboard or a timeline.

Your own Bundle

Paste a Bundle, choose a .json file or drop one on this box. It is read in this browser tab only - nothing is uploaded, and there is no server to upload it to.

Use it on your page

One script tag, no build step and no dependencies. The element fetches the Bundle from src, or takes it as a property.

<script type="module"
  src="https://cdn.jsdelivr.net/gh/vadi2/fhir-document-viewer@0.1.2/fhir-document-viewer.js"></script>

<fhir-document-viewer src="patient-summary.json" view="dashboard"></fhir-document-viewer>
// or hand it a Bundle you already have, as JSON text or a parsed object
document.querySelector("fhir-document-viewer").bundle = bundleJson;
  • Patient summaries (HL7 IPS, HL7 Europe EPS): every section, with the three kinds of empty kept apart and the sections the guide expects but the document did not send.
  • Laboratory reports, prescriptions and dispenses, imaging reports, hospital discharge reports: recognised and read with the same rules; a prescription Bundle without a Composition is shown as one list of entries.
  • Any other FHIR R4 document Bundle is read section by section.

More in the README, and a machine-readable outline in llms.txt.

Lifted out of Provbana, the open source platform for FHIR document tracks at hackathons, where this view was built for the Nordic Hackathon 2026. MIT licensed. It is a reading aid for developers and testers, not a medical device: do not use it to make decisions about real patients.
